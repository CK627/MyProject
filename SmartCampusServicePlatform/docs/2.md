本章通过界面截图配合功能描述，全面展示智慧校园服务平台的各项功能模块及其运行效果。

## 2.1 用户注册与登录

### 2.1.1 注册页面

**截图1：用户注册页面**

> （此处插入注册页面截图）

**功能说明：**

- **注册表单**：用户需填写邮箱、密码、确认密码、姓名、手机号码等基本信息完成注册。邮箱作为登录账号，系统会校验邮箱格式和是否已被注册。
- **密码安全**：密码采用bcrypt算法加密存储，即使数据库泄露也无法还原明文密码。
- **表单验证**：前端对输入内容进行实时校验（如邮箱格式、密码长度、两次密码一致性），不合规时给出即时提示。

### 2.1.2 登录页面

**截图2：用户登录页面**

> （此处插入登录页面截图）

**功能说明：**

- 用户输入注册时使用的邮箱和密码进行登录。
- 登录成功后，系统签发JWT令牌，后续所有请求通过令牌验证身份，无需重复登录。
- 登录失败时，页面会显示明确的错误提示（如"邮箱或密码错误"）。
- **忘记密码入口**：登录表单下方提供"忘记密码？"链接，点击后在页面内展开密码重置面板，用户可输入注册邮箱发送重置链接（详见2.1.3节）。
- **第三方登录（可选配置）**：平台支持通过GitHub OAuth进行第三方登录。用户点击"使用 GitHub 登录"按钮后，系统弹出GitHub授权窗口，授权成功后自动完成登录并获取用户信息。该功能需要在服务端配置GitHub OAuth应用凭据（`NEXT_PUBLIC_GITHUB_CLIENT_ID`），属于**可选配置功能**，未配置时该按钮点击后会提示配置信息。

### 2.1.3 忘记密码与密码重置

**截图3：忘记密码面板**

> （此处插入忘记密码面板截图）

**截图4：密码重置页面**

> （此处插入密码重置页面截图）

**功能说明：**

- **忘记密码入口**：在登录页面点击"忘记密码？"链接后，页面下方展开重置密码面板。用户输入注册时使用的邮箱地址，点击"发送重置链接"按钮，系统向该邮箱发送包含重置令牌的链接。出于安全考虑，无论邮箱是否已注册，页面均显示统一的提示信息"如果该邮箱已注册，重置链接已发送到您的邮箱"，避免暴露用户注册信息。
- **密码重置页面**：用户通过邮件中的链接跳转至独立的密码重置页面（`/reset-password?token=xxx`）。页面提供新密码和确认密码两个输入框，支持密码显示/隐藏切换。系统对密码长度进行校验（至少6位），并验证两次输入的一致性。
- **异常处理**：若重置链接无效或已过期，页面显示醒目的错误图标和提示文字"该链接无效或已过期，请重新申请密码重置"，并提供"返回首页"按钮引导用户重新操作。重置成功后显示绿色成功图标和"密码重置成功"提示，引导用户使用新密码登录。

### 2.4.1 任务列表页

**截图10：互助任务列表页**

- 支持按分类筛选（跑腿代办、代购物品、学习辅导、其他）。

### 2.4.2 发布任务

**截图11：发布任务页面**

> （此处插入发布任务页面截图）

**功能说明：**

- 用户填写任务标题、详细描述、任务分类、悬赏金额等信息。
- **悬赏冻结机制**：发布任务时，悬赏金额从钱包余额中扣除并冻结，确保发布者有能力支付报酬。余额不足时无法发布。
- **私密信息**：支持填写快递取件码等敏感信息，该信息仅在任务被接单后对接单者可见。
- 任务提交后进入审核流程，审核通过后在任务列表公开展示。

### 2.4.3 任务详情与接单流程

**截图12：任务详情页**

> （此处插入任务详情页截图）

**功能说明：**

任务详情页展示任务的完整信息，并承载整个接单交易流程：

- **任务信息展示**：标题、描述、分类、地点、截止时间、悬赏金额。
- **发布者信息**：头像、昵称、信誉分和好评率，帮助接单者判断任务可信度。
- **申请接单**：其他用户点击"申请接单"按钮提交申请。
- **选择接单者**：发布者在申请列表中查看所有申请者的信誉信息，申请者按优先分（信誉分+好评率综合计算）排序，发布者从中选择一位接单。
- **确认完成**：接单者完成任务后，发布者点击"确认完成"，冻结的悬赏金额自动发放给接单者。
- **取消任务**：未被接单的任务可以取消，冻结金额退回钱包。

### 2.4.4 完整交易流程

整个互助任务从发布到完成的流程如下：

1. 发布者发布任务并设置悬赏 → 悬赏金额从钱包冻结
2. 其他用户浏览任务列表并申请接单
3. 发布者从申请列表中选择接单者 → 任务状态变为"进行中"
4. 接单者可查看私密信息（如快递码），执行任务
5. 发布者确认任务完成 → 悬赏发放给接单者
6. 双方互相评价 → 影响各自的信誉分和好评率

**截图20：修改密码对话框**

> （此处插入修改密码对话框截图）

**功能说明：**

- **密码强度检测**：输入新密码时，下方实时显示密码强度指示条，分为三个等级——"弱"（红色，密码较短或过于简单）、"中"（黄色，包含一定复杂度）、"强"（绿色，长度充足且包含大小写、数字、特殊字符）。强度评估综合考虑密码长度（≥6位、≥8位）、大小写字母混用、数字包含和特殊字符使用等因素。
- **安全验证**：修改密码前需先验证当前密码的正确性，确认新密码两次输入一致后方可提交。修改成功后显示成功提示，对话框自动关闭。

| 恶意评论 | -2 | 低 |

### 2.9.2 评论社区治理

平台采用"社区投票+审核员投票"的双轨评论治理机制：

- **社区投票**：普通用户可对评论进行拉踩操作，当一条评论的拉踩数超过"点赞数x2+5"时，系统自动删除该评论，评论发布者信誉分-2。
- **审核员投票**：信誉分超过98的用户自动成为审核员，审核员可对违规评论投票删除，累计3票即删除，评论发布者信誉分-5。

这种机制让社区内容质量的维护不完全依赖管理员，而是由全体用户共同参与。
