# 第一章：项目概述与设计目标

## 1.1 选题背景

在高校校园生活中，学生的日常需求远不止于课堂学习。每年毕业季，大量闲置教材、电子产品、生活用品被丢弃或低价处理，造成资源浪费；学生在日常生活中经常遇到代取快递、代买物品、学习辅导等小型互助需求，却苦于缺乏可信赖的对接渠道；校园公告、社团活动等信息分散在微信群、QQ群和各类公告栏中，获取效率低下；新生入学、跨专业交流等场景下，学生也缺少一个安全、有针对性的社交平台。

目前，学生们大多通过微信群、QQ群等通用社交工具来满足上述需求。但这些工具并非为校园互助场景专门设计，存在信息易被刷屏淹没、缺乏信任保障机制、无法进行结构化的任务管理和交易流程等问题。而闲鱼等外部交易平台虽然功能完善，但面向校园内部小额互助时存在物流成本高、面交缺乏保障等局限。

因此，设计并实现一个面向高校师生的智慧校园服务平台，将互助任务、社交动态、即时通讯、信誉评价等功能整合于一体，具有重要的现实意义和应用价值。

## 1.2 平台定位

本平台定位为一个**面向高校师生的校园互助服务平台**，打造一个集校园墙动态、互助任务、即时通讯、钱包交易、信誉评价于一体的一站式校园服务门户。

平台的核心理念是"**互助共享，安全可信**"：

- **互助共享**：学生可以发布互助任务、分享校园动态，形成活跃的校园互助社区
- **安全可信**：通过信誉分、好评率、内容审核等机制，保障用户权益和社区质量
- **一站式服务**：无需在多个平台间跳转，校园生活中的互助、社交、信息获取都能在一个平台完成

## 1.3 设计目标

本平台的设计目标可从以下四个维度进行阐述：

### 1.3.1 易用性目标

- 界面风格简洁现代，操作流程清晰直观，用户注册后即可快速上手
- 采用响应式布局，适配PC和移动端浏览器，随时随地访问
- 关键操作（如发布任务、联系对方）路径短，减少用户操作步骤

### 1.3.2 安全性目标

- 采用JWT令牌认证和bcrypt密码加密，保障账户安全
- 建立信誉分和好评率相结合的用户信誉体系，筛选可信用户
- 帖子发布需经审核，评论支持社区投票删除，维护社区内容质量
- 任务中的敏感信息（如快递取件码）仅对接单者可见，保护用户隐私

### 1.3.3 功能完整性目标

- 覆盖校园互助的核心场景：动态发布、任务悬赏、即时通讯、钱包交易、信誉评价
- 从发布任务到完成交易的全流程可在平台内闭环完成
- 提供好友管理、消息通知、个人中心等配套功能

### 1.3.4 可扩展性目标

- 采用前后端分离架构和模块化设计，功能模块相互独立
- 核心业务参数可配置，支持多种数据库（SQLite、MySQL、PostgreSQL）
- 代码结构清晰，便于后续扩展二手交易、校园跑腿等新功能
