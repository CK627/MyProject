# 微信JS接口安全域名配置指南

## 问题描述

当前微信导航功能无法使用，错误信息：`config:invalid url domain`

**原因：** 当前访问域名 `172.16.100.31:8000` 没有在微信公众平台的JS接口安全域名中配置。

## 解决方案

### 方案一：配置JS接口安全域名（推荐）

#### 1. 登录微信公众平台
- 访问：https://mp.weixin.qq.com
- 使用微信公众号管理员账号登录

#### 2. 进入功能设置
1. 点击左侧菜单：**设置与开发** → **公众号设置**
2. 选择 **功能设置** 标签页
3. 找到 **JS接口安全域名** 设置项

#### 3. 添加安全域名
根据你的使用场景选择：

**测试环境（当前）：**
```
172.16.100.31:8000
```

**生产环境（推荐）：**
```
yourdomain.com
```

#### 4. 域名验证
1. 点击 **设置** 按钮
2. 下载微信提供的验证文件（如：MP_verify_xxxxxxxxx.txt）
3. 将验证文件上传到网站根目录
4. 确保可以通过以下URL访问：
   ```
   http://172.16.100.31:8000/MP_verify_xxxxxxxxx.txt
   ```
5. 点击 **确认** 完成验证

### 方案二：使用正式域名（生产环境推荐）

#### 1. 准备域名
- 购买并配置一个正式域名（如：conference.yourdomain.com）
- 将域名解析到你的服务器IP

#### 2. 配置HTTPS（推荐）
微信建议使用HTTPS协议：
```bash
# 使用Let's Encrypt获取免费SSL证书
sudo certbot --nginx -d conference.yourdomain.com
```

#### 3. 在微信公众平台配置域名
按照方案一的步骤，添加正式域名：
```
conference.yourdomain.com
```

### 方案三：本地测试替代方案

如果暂时无法配置域名，可以使用以下替代方案：

#### 1. 使用微信开发者工具
- 下载微信开发者工具
- 在工具中打开页面进行测试
- 开发者工具会忽略域名限制

#### 2. 使用内网穿透工具
使用ngrok等工具创建临时域名：
```bash
# 安装ngrok
npm install -g ngrok

# 创建隧道
ngrok http 8000
```
然后使用ngrok提供的域名进行配置。

- 检查是否能正常调用微信地图

- 在微信开发者工具中打开页面
- 查看Console是否有错误信息

## 常见问题

### Q1: 域名验证文件无法访问
**解决方案：**
- 确保文件放在网站根目录
- 检查文件权限（644）
- 确保Web服务器正常运行

### Q2: 配置后仍然报错
**解决方案：**
- 等待5-10分钟，微信配置有缓存
- 清除微信缓存重新进入页面
- 检查域名是否完全匹配（包括端口号）

### Q3: HTTPS证书问题
**解决方案：**
- 确保SSL证书有效
- 检查证书链完整性
- 使用在线SSL检测工具验证
