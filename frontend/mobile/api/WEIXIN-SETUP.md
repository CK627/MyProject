# 微信JS-SDK配置指南

## 概述
本项目已集成微信JS-SDK，支持微信内置地图导航功能。您已提供了必要的证书和密钥文件，现在需要完成最后的配置步骤。

- ✅ `非对称密钥.txt` - 非对称私钥
- ✅ `对称密钥.txt` - 对称密钥
- ✅ `weixin-config.php` - 微信JS-SDK签名服务
- ✅ `weixin-secret.php` - 微信配置文件

## 配置步骤

### 1. 获取AppSecret
1. 登录微信公众平台：https://mp.weixin.qq.com
2. 进入"开发" -> "基本配置"
3. 复制"AppSecret"（应用密钥）

### 2. 配置AppSecret
编辑 `weixin-secret.php` 文件，将AppSecret填入：
```php
'appSecret' => '您的AppSecret', // 替换为实际的AppSecret
```

### 3. 配置JS接口安全域名
1. 在微信公众平台，进入"设置与开发" -> "公众号设置" -> "功能设置"
2. 在"JS接口安全域名"中添加您的域名（不包含http://或https://）
3. 例如：`yourdomain.com` 或 `subdomain.yourdomain.com`

### 4. 测试配置
1. 在微信中打开交通指引页面
2. 点击"导航"按钮
3. 如果配置正确，会打开微信内置地图并显示目标位置

## 故障排除

### 常见问题

1. **点击导航按钮无反应**
   - 检查是否在微信环境中打开
   - 确认JS接口安全域名已正确配置
   - 查看浏览器控制台是否有错误信息

2. **提示"config:invalid signature"**
   - 检查AppSecret是否正确配置
   - 确认当前域名已添加到JS接口安全域名
   - 检查服务器时间是否正确

3. **提示"config:invalid url domain"**
   - 确认当前访问域名已添加到JS接口安全域名
   - 注意域名不要包含端口号（除非微信平台也配置了端口号）

### 调试模式
如需开启调试模式，修改 `weixin-secret.php`：
```php
'debug' => true, // 开启调试模式
```

开启后，微信JS-SDK的所有API调用结果会通过alert显示。

## 安全注意事项

1. **保护敏感信息**
   - `weixin-secret.php` 包含敏感配置，不要提交到版本控制
   - 确保服务器文件权限设置正确

2. **域名安全**
   - 只在可信域名上配置JS接口安全域名
   - 定期检查和更新安全配置

3. **证书管理**
   - 定期检查证书有效期
   - 及时更新过期证书
