# 福建师范大学广东校友会一周年庆典晚会系统

## 项目概述

这是一个为福建师范大学广东校友会一周年庆典晚会开发的综合性活动管理系统。系统以"就爱你"为主题，提供了完整的活动报名、管理、直播和座位安排等功能。

### 项目背景
- **活动名称**: 福建师范大学广东校友会一周年庆典晚会
- **活动主题**: "就爱你"主题活动
- **活动时间**: 2025年9月20日（920）
- **目标用户**: 福建师范大学广东校友及其家属

## 系统架构

### 技术栈
- **前端**: HTML5, CSS3, JavaScript (ES6+), Bootstrap 5.1.3
- **后端**: PHP 7.4+, MySQL 8.0
- **数据库**: MySQL (远程服务器: fnu.mtserver.fun)
- **图表库**: Chart.js
- **Excel处理**: ExcelJS
- **响应式设计**: 支持桌面端和移动端

## 核心功能模块

### 1. 用户端功能 (Frontend)

#### 1.1 桌面端功能
- **主页展示**: 活动介绍、统计数据展示
- **活动报名**: 完整的报名表单，支持家属报名
- **座位信息**: 查看座位安排
- **活动议程**: 详细的活动时间安排
- **照片直播**: 实时活动照片展示
- **视频直播**: 活动视频直播功能
- **交通指引**: 活动地点交通信息
- **背景音乐**: 可控制的背景音乐播放

#### 1.2 移动端功能
- **响应式设计**: 适配各种移动设备
- **触摸优化**: 针对移动端优化的交互体验
- **音频控制**: 移动端背景音乐控制
- **页面状态检查**: 自动检查页面状态并跳转

#### 1.3 报名系统特色
- **时间控制**: 基于系统设置的报名时间验证
- **多种支付方式**: 支持微信、支付宝等多种支付方式
- **付款凭证上传**: 支持上传付款截图（JPEG、PNG、GIF格式，最大5MB）
- **才艺表演报名**: 支持才艺表演项目报名和详情填写
- **家属报名**: 支持携带家属参加活动
- **实时验证**: 手机号、姓名等字段的实时验证

### 2. 管理端功能 (Backend)

#### 2.1 仪表板
- **数据统计**: 总报名人数、节目数量、签到统计等
- **图表展示**: 使用Chart.js展示各类统计图表
- **实时更新**: 数据实时刷新和动画效果

#### 2.2 报名管理
- **报名列表**: 分页显示所有报名信息
- **搜索过滤**: 支持按姓名、手机号、才艺表演等条件搜索
- **批量操作**: 批量更新、删除报名信息
- **详情编辑**: 单个报名信息的详细编辑
- **付款凭证管理**: 查看和管理用户上传的付款凭证

#### 2.3 数据导入导出
- **Excel导出**: 支持导出报名数据到Excel，包含图片嵌入
- **CSV导出**: 支持CSV格式数据导出
- **数据导入**: 支持从CSV文件导入座位信息
- **图片处理**: 自动处理和优化导出的图片

#### 2.4 座位管理
- **座位分配**: 为报名用户分配座位号
- **签到管理**: 管理用户签到状态
- **座位查询**: 支持按各种条件查询座位信息
- **批量操作**: 批量分配座位和更新签到状态

#### 2.5 系统设置
- **报名时间设置**: 配置报名开始和结束时间
- **页面状态管理**: 控制各个页面的显示状态
- **系统参数配置**: 各种系统参数的配置管理

#### 2.6 页面管理
- **页面状态控制**: 控制前端页面是否显示或跳转到建设中页面
- **PC端页面管理**: 管理桌面端各个页面状态
- **移动端页面管理**: 管理移动端各个页面状态

## 数据库设计

### 主要数据表

#### 1. registrations (报名表)
- **id**: 主键，自增ID
- **name**: 姓名 (varchar(20))
- **phone**: 手机号 (varchar(11))
- **is_2025_student**: 是否为2025届学生 (tinyint)
- **education_info**: 教育信息 (text)
- **family_count**: 家属人数 (int)
- **talent_show**: 才艺表演类型 (varchar(100))
- **talent_description**: 才艺表演详情 (text)
- **material_sponsorship**: 物资赞助 (text)
- **remarks**: 备注 (text)
- **payment_method**: 支付方式 (varchar(50))
- **payment_screenshot**: 付款凭证1 (varchar(255))
- **payment_screenshot_2**: 付款凭证2 (varchar(255))
- **total_amount**: 总金额 (decimal(10,2))
- **seat_number**: 座位号 (varchar(10))
- **is_checked_in**: 是否已签到 (tinyint)
- **checkin_time**: 签到时间 (timestamp)
- **created_at**: 创建时间 (timestamp)
- **updated_at**: 更新时间 (timestamp)

#### 2. systems (系统设置表)
- **id**: 主键，自增ID
- **setting_key**: 设置键名 (varchar(100))
- **setting_value**: 设置值 (text)
- **setting_description**: 设置描述 (varchar(255))
- **created_at**: 创建时间 (timestamp)
- **updated_at**: 更新时间 (timestamp)

#### 3. import_info (导入信息表)
- **id**: 主键，自增ID
- **name**: 姓名 (varchar(100))
- **phone**: 手机号 (varchar(20))
- **seat_number**: 座位号 (varchar(10))
- **is_checked_in**: 是否已签到 (tinyint)
- **created_at**: 创建时间 (timestamp)
- **updated_at**: 更新时间 (timestamp)

### 1. 时间控制系统
- 基于数据库配置的报名时间控制
- 当前时间: 2025-07-22 00:53:33 (CST)

## API接口文档

### 前端API接口
- **GET /api/index.php**: 获取首页统计数据
- **POST /api/registrations.php**: 提交报名信息
- **GET /api/registrations.php**: 获取报名列表
- **GET /api/page-status.php**: 检查页面状态
- **GET /api/seating.php**: 获取座位信息

### 后端API接口
- **GET /api/dashboard.php**: 获取仪表板数据
- **GET /api/registrations.php**: 报名管理接口
- **POST /api/registrations-modify.php**: 修改报名信息
- **GET /api/systems.php**: 系统设置接口
- **GET /api/charts.php**: 图表数据接口
- **POST /api/import.php**: 数据导入接口
- **GET /api/seatings.php**: 座位管理接口
