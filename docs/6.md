# 第六章 总结与展望

做完这个毕业设计以后，我最大的感受是，一个看起来流程并不算特别复杂的活动管理系统，真正动手去做的时候还是会遇到很多具体问题。比如前期报名信息怎么统一收集，后台数据怎么分类整理，付款截图怎么审核，座位号怎么分配，现场签到状态又怎样及时更新，这些内容单独看都不难，但真正放到一个系统里以后，就要求前端页面、后端接口和数据库之间能够比较顺畅地配合起来。通过这次课题，我完成了校友会庆典活动管理系统的设计与实现，系统基本实现了在线报名、后台审核、才艺申报、座位分配、二维码签到和数据导出等主要功能，能够满足活动筹备和现场使用中的基本需求。和以前主要依靠人工登记、表格统计的方式相比，这套系统在信息集中管理、数据查询和状态更新方面都更直接一些，也减少了后期重复整理数据的工作量。从实际效果来看，本课题达到了预期目标，也说明把这类中小型活动管理工作放到 Web 系统中处理是可行的。不过，本系统仍然存在一些不足，例如支付环节目前还是依靠人工核对，部分功能在细节体验上还不够完善，数据分析和统计展示也还比较基础。如果后续继续改进，我认为可以从在线支付接入、图表统计优化以及移动端操作体验几个方面继续完善，这样系统的完整性和实用性还能够进一步提高。对我自己来说，这次毕业设计最大的收获不只是完成了一个项目，更重要的是对需求分析、功能设计、编码实现和后期测试这一整套开发过程有了更具体的认识，也让我把在学校学到的相关知识真正结合到了一次完整实践当中。
