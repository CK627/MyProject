### 5.1.2 登录验证

**截图24：登录错误提示**

> （此处插入用户名或密码错误时的提示截图）

**功能说明：**

管理员提交登录信息后，系统会先检查输入是否完整：如果用户名或密码为空，会直接提示“请输入用户名和密码”。当账号或密码不正确时，会提示“用户名或密码错误”。只有在验证通过后，系统才会写入登录Session并跳转到仪表盘页面，进入后台管理流程。

**核心实现代码：**

```php
// 验证登录
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $username = sanitizeInput($_POST['username']);
    $password = $_POST['password'];
    
    if (empty($username) || empty($password)) {
        $error = '请输入用户名和密码';
    } elseif (verifyAdmin($username, $password)) {
        // 登录成功，设置Session
        $_SESSION['admin_logged_in'] = true;
        $_SESSION['admin_username'] = $username;
        header('Location: dashboard.php');
        exit;
    } else {
        $error = '用户名或密码错误';
    }
}
```

## 5.8 退出登录

**截图40：退出登录**

> （此处插入退出按钮和退出后跳转截图）

**功能说明：**

点击顶部导航的“退出”按钮后，系统会清理当前登录状态并销毁Session，随后自动跳回登录页面；退出完成后再次访问后台页面需要重新登录。

**核心实现代码：**

```php
// 销毁登录Session
function destroyLoginSession() {
    $_SESSION = [];
    if (ini_get('session.use_cookies')) {
        $params = session_get_cookie_params();
        setcookie(session_name(), '', time() - 42000,
            $params['path'], $params['domain'],
            $params['secure'], $params['httponly']);
    }
    session_destroy();
}
```

## 5.9 权限保护

**功能说明：**

后台页面统一做了登录态校验：未登录时访问任何后台地址都会被重定向到登录页；如果Session过期或失效，也需要重新登录后才能继续使用管理功能。

**核心实现代码：**

```php
// 在每个后台页面开头调用
function checkAuth() {
    if (!isset($_SESSION['admin_logged_in']) || $_SESSION['admin_logged_in'] !== true) {
        header('Location: login.php');
        exit;
    }
}
```

## 5.10 本章小结

本章主要展示了管理员在后台是怎么干活的。为了让网站上的信息一直新鲜靠谱，管理员得在后台加上新景点、修改旧菜价；同时，对游客写在留言板上的东西，管理员也能在这个系统里进行审核和清理，免得出现不合适的内容。整个后台的界面都做得比较统一，各项管理功能都清清楚楚地摆在那里，日常维护起来就很方便。
