# 第二章 相关技术简介

## 2.1 开发环境

本系统的开发环境配置如下：

| 项目 | 配置 |
|------|------|
| 操作系统 | Windows 11 / macOS |
| 代码编辑器 | Visual Studio Code |
| 本地服务器 | XAMPP（Apache + MySQL + PHP） |
| 浏览器 | Google Chrome |
| 数据库工具 | phpMyAdmin |

## 2.2 前端技术

### 2.2.1 HTML5

HTML5是网页的骨架，用于构建页面结构。本项目使用HTML5的语义化标签组织页面内容，使结构更加清晰。

### 2.2.2 CSS3

CSS3用于美化页面样式。本项目主要使用以下CSS3特性：

- **Flexbox布局**：实现灵活的页面排版
- **媒体查询**：实现响应式设计，适配不同屏幕
- **CSS变量**：统一管理配色方案
- **过渡动画**：提升交互体验

### 2.2.3 JavaScript

JavaScript用于实现页面的动态交互功能，主要包括：

- 动态生成导航栏和页脚
- 调用API加载数据并渲染
- 图片懒加载优化性能
- 表单验证和提交处理

## 2.3 后端技术

### 2.3.1 PHP

PHP是服务器端脚本语言，本项目用于：

- 编写RESTful API接口
- 连接和操作MySQL数据库
- 处理用户登录验证
- 处理文件上传

### 2.3.2 MySQL

MySQL是关系型数据库，用于存储系统的各类数据，包括景点、美食、住宿、交通、攻略、留言、评论等信息。

## 2.4 核心技术实现

### 2.4.1 响应式布局实现

通过CSS媒体查询实现响应式设计：

```css
/* PC端三列布局 */
.grid { display: grid; grid-template-columns: repeat(3, 1fr); }

/* 平板端两列 */
@media (max-width: 1024px) {
  .grid { grid-template-columns: repeat(2, 1fr); }
}

/* 手机端单列 */
@media (max-width: 768px) {
  .grid { grid-template-columns: 1fr; }
}
```

### 2.4.2 图片懒加载实现

使用IntersectionObserver API实现图片懒加载，优化页面加载速度：

```javascript
function initLazyLoad() {
  var images = document.querySelectorAll('img[data-src]');
  var observer = new IntersectionObserver(function(entries) {
    entries.forEach(function(entry) {
      if (entry.isIntersecting) {
        var img = entry.target;
        img.src = img.dataset.src;  // 加载真实图片
        observer.unobserve(img);
      }
    });
  });
  images.forEach(function(img) { observer.observe(img); });
}
```

### 2.4.3 API数据交互

前端通过Fetch API与后端进行数据交互：

```javascript
// 获取景点列表
fetch('api/public/get_spots.php?category=自然风光')
  .then(function(res) { return res.json(); })
  .then(function(data) {
    if (data.code === 0) {
      renderCards(data.data.list);  // 渲染卡片
    }
  });
```

### 2.4.4 PDO数据库操作

后端使用PDO预编译语句操作数据库，防止SQL注入：

```php
$db = getDB();
$stmt = $db->prepare("SELECT * FROM spots WHERE category = :category");
$stmt->execute([':category' => $category]);
$spots = $stmt->fetchAll();
```

## 2.5 本章小结

本章介绍了系统开发所使用的技术栈。前端采用HTML5+CSS3+JavaScript构建响应式页面，后端采用PHP+MySQL实现数据管理。核心技术包括响应式布局、图片懒加载、API数据交互和安全的数据库操作。
