# 第二章 开发技术与环境

## 2.1 前端开发技术
### 2.1.1 HTML5与CSS3
在前端部分，我主要使用了 HTML5 和 CSS3 来完成页面搭建。之所以选择这两种技术，原因比较直接，一方面是它们本身就是 Web 页面开发的基础，另一方面是和本项目的界面需求比较匹配。系统里既有报名页面，也有后台管理页面，结构上并不算特别复杂，用 HTML5 来划分页面区域已经足够，而 CSS3 则主要用来处理配色、间距、按钮样式和页面布局。

### 2.1.2 JavaScript (ES6+)
JavaScript 在本系统里主要不是拿来做复杂动画，而是处理实际交互。比如报名表单提交、后台数据加载、页面切换、按钮点击后的提示信息，这些都需要靠 JavaScript 来完成。因为系统里的很多数据都要实时从后端读取，所以使用 JavaScript 做异步请求会比较方便，也能让页面不用频繁刷新。

### 2.1.3 Bootstrap框架
为了节省页面开发时间，我还使用了 Bootstrap。这个框架最适合本项目的地方在于它已经提供了很多现成的样式和组件，例如表单、按钮、弹窗、表格和栅格布局。这样做的好处不是为了追求多高级的前端效果，而是能更快把功能页面搭起来，同时让前台和后台的整体风格保持统一。

## 2.2 后端开发技术
### 2.2.1 PHP语言
后端部分我选择了 PHP。选择它的原因并不是单纯因为常见，而是因为这个项目本身就是典型的 Web 管理系统，PHP 在处理表单提交、接口编写和数据库交互方面比较直接，上手也快。对于这次毕业设计来说，用 PHP 可以把主要精力放在业务功能实现上，而不是花太多时间处理框架配置问题。

### 2.2.2 JSON数据交互
前后端数据交互使用的是 JSON 格式。这样做比较符合本项目的实际情况，因为前端是用 JavaScript 读取数据，JSON 解析起来很方便，字段结构也清楚，后面调试接口时也更直观。

## 2.3 数据库技术
### 2.3.1 MySQL数据库
数据库方面选择 MySQL，主要是考虑到它比较成熟，资料多，而且和 PHP 配合使用很常见。项目中像报名信息、付款截图路径、签到状态、座位号和系统配置这些内容，都需要统一存放到数据库里，如果没有数据库支撑，后面很多功能都没法正常联动。

### 2.3.2 数据库连接
在数据库连接方式上，系统使用了 PDO。这样写一方面结构更规范一些，另一方面也支持预处理，后续在做数据查询和修改的时候更安全，代码也更容易统一管理。

## 2.4 开发工具
- **代码编辑器**：开发过程中主要使用 Visual Studio Code，用来编写前端页面、后端接口和脚本文件。
- **数据库管理工具**：使用 Navicat 或 phpMyAdmin 查看表结构、检查数据和做必要的修改。
- **版本管理工具**：使用 Git 记录项目修改过程，防止代码改乱以后无法恢复。
- **接口调试工具**：使用 Postman 测试接口返回的数据，方便排查前后端联调时的问题。
