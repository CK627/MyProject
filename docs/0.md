# 摘要

这次毕业设计不是单纯做一个展示页面，而是结合福建师范大学广东校友会一周年庆典活动的实际需要来完成的。因为这类活动在准备阶段会涉及报名登记、信息统计、付款核对、座位安排和现场签到等很多事情，如果一直靠人工整理，不但效率不高，而且后面查找和修改也很麻烦，所以我想把这些常用流程尽量集中到一个系统里处理。

本系统采用 B/S 架构开发，前端主要使用 HTML5、CSS3、JavaScript 和 Bootstrap，后端使用 PHP，数据库使用 MySQL。系统完成了在线报名、才艺申报、后台审核、座位分配、二维码签到和数据导出等功能，能够满足活动前期整理和现场使用的基本需求。

从测试情况来看，系统整体运行比较稳定，常用功能也能够正常使用。和原来主要依靠人工登记、表格统计的方式相比，使用系统之后，信息整理会更集中，查询也更方便，尤其是在移动端报名和现场签到这两个环节，实际使用起来会更直观一些。总体来说，这个系统基本达到了本课题预期的设计目的，也说明把中小型活动管理做成信息化工具是可行的。

**关键词**：校友会；活动管理系统；PHP；MySQL；二维码签到；响应式设计
