# 摘要

近年来，高校的信息化建设虽然取得了显著进展，但学生的校园生活依然面临诸多不便。比如，二手物品闲置造成的资源浪费、同学之间互助需求难以高效对接，以及校园资讯往往散落在不同的社交群组中。为了解决这些实际痛点，本文开发了一套“智慧校园服务平台”。

整个系统采用主流的前后端分离（B/S）架构。前端界面使用 Next.js 和 React 结合 TypeScript 进行开发，重点优化了跨设备的响应式体验；后端则选用了轻量且高性能的 Python FastAPI 框架，兼容 SQLite 和 MySQL 等多种数据库。

在功能层面，平台不仅包含基础的用户注册与权限管理，还重点打造了几个核心模块：
首先是校园墙，学生可以在这里发布动态和交流互动；
其次是互助任务大厅，结合了虚拟钱包的悬赏冻结机制，让代取快递、二手交易等任务能够安全流转；
第三是引入了原生 WebSocket 技术，开发了低延迟的即时通讯功能，方便发单人和接单人直接沟通；
最后，为了保证平台风气，系统设计了一套信誉积分评价模型。高分用户不仅接单更有优势，还能晋升为审核员，参与社区违规内容的自治管理。

经过一系列的功能与流程测试，平台各模块运行稳定。本系统的实现，为高校内闲置资源的流转和学生间的互助协作提供了一个安全、透明且易于维护的数字化解决方案。

**关键词**：智慧校园；前后端分离；React；FastAPI；WebSocket；校园互助
