# 第四章 系统详细实现

本章将重点展示系统的核心功能界面及实现效果。

## 4.1 前端功能实现
前端主要面向广大校友，界面设计力求简洁大气，操作流畅。

### 4.1.1 系统首页
系统首页是校友进入的第一站，展示了庆典活动的主题海报、倒计时以及核心功能入口（报名、查询、签到等）。

**功能描述**：
*   展示活动主题：“福建师范大学广东校友会一周年庆典”。
*   提供“立即报名”、“我的报名”、“活动议程”等快捷按钮。
*   采用响应式布局，自动适配手机和电脑屏幕。

![系统首页截图](此处放置系统首页截图.png)
*图4-1 系统首页界面*

### 4.1.2 在线报名页面
这是系统最核心的功能之一。校友需要在此填写详细信息完成报名。

**功能描述**：
*   表单包含：姓名、届别、联系电话、工作单位等必填项。
*   特色功能：支持选择是否携带家属（自动计算费用）、申报才艺表演。
*   支付凭证上传：用户付款后截图上传，后台进行人工审核。

**关键代码片段（前端验证逻辑）**：
```javascript
// 简单的表单验证示例
function validateForm() {
    let name = document.getElementById("name").value;
    let phone = document.getElementById("phone").value;
    if (name == "" || phone == "") {
        alert("请填写完整信息！");
        return false;
    }
    return true;
}
```

### 4.1.3 报名结果与个人中心
报名提交后，校友可以查看报名状态（待审核、已通过）。审核通过后，系统会生成专属的签到二维码和座位号。

## 4.2 后端管理功能实现
后台管理系统供校友会工作人员使用，用于数据的审核、统计和现场管控。

### 4.2.1 管理员登录
为了保证数据安全，管理员必须通过账号密码登录才能进入后台。

![后台登录页面截图](此处放置后台登录页面截图.png)
*图4-4 后台登录页面*

### 4.2.2 数据仪表盘 (Dashboard)
登录后首先看到的是数据仪表盘，直观展示活动的各项关键指标。

**功能展示**：
*   **报名总人数**：实时更新。
*   **资金统计**：已确认的报名费用总额。
*   **签到进度**：现场签到人数与总人数的比例图表。

![数据仪表盘截图](此处放置数据仪表盘截图.png)
*图4-5 后台数据仪表盘*

### 4.2.3 报名信息管理
管理员在此页面对报名信息进行审核和管理。

**操作流程**：
1.  查看待审核列表。
2.  核对付款凭证图片。
3.  点击“通过”或“拒绝”。
4.  支持导出Excel表格，方便线下打印或备份。

![报名管理页面截图](此处放置报名管理页面截图.png)
*图4-6 报名信息管理列表*

### 4.2.4 现场签到管理
活动当天，管理员使用此功能进行扫码签到或手动签到。

**功能描述**：
*   **扫码签到**：调用摄像头扫描校友出示的二维码。
*   **手机号签到**：输入手机后四位快速查找并签到。
*   **状态同步**：签到成功后，前台个人中心同步更新为“已签到”。
