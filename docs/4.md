### 4.1.3 精选景点推荐

**截图3：精选景点展示区**

> （此处插入精选景点3张卡片截图，如天一阁、东钱湖、溪口雪窦山）

**界面说明：**

首页中段会挑选三处热门景点做推荐展示，这部分内容从数据库读取后动态生成卡片。卡片上能看到景点图片、所属分类、名称与简短介绍，同时也会露出等级、地址等关键信息；用户点进卡片即可进入该景点的详情页。卡片列表下方还放了“查看全部景点”的入口，用来跳转到完整景点列表继续浏览。

**核心实现代码：**

```javascript
// 从API加载精选景点
fetch('api/public/get_spots.php?pageSize=3')
  .then(function(res) { return res.json(); })
  .then(function(result) {
    if (result.code === 0) {
      var html = '';
      result.data.list.forEach(function(spot) {
        html += '<div class="card">' +
          '<img data-src="' + spot.image + '" class="lazy-img">' +
          '<span class="card__badge">' + spot.category + '</span>' +
          '<h3>' + spot.name + '</h3>' +
          '<p>' + spot.description + '</p>' +
        '</div>';
      });
      document.getElementById('featuredSpotsGrid').innerHTML = html;
    }
  });
```
