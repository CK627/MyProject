# 结论

​	本课题设计并实现了一个以宁波旅游宣传为主题的网页系统，经过需求分析、系统设计与编码实现，顺利完成了预定目标。系统分为前台展示与后台管理两大模块：前台涵盖首页、景点、美食、住宿、交通、攻略及游客留言等七个功能模块，全面展示宁波旅游资源，支持分类筛选与关键词搜索；后台则实现管理员登录、内容管理、留言审核等功能，支持图片上传与富文本编辑，便于信息更新与维护。在技术实现上，系统采用响应式设计，通过CSS媒体查询自适应PC端、平板和手机等不同设备，移动端以汉堡菜单和单列布局优化用户体验；同时引入图片懒加载技术减少首屏加载时间，结合滚动动画与统一视觉风格，提升页面性能与美观度。

​	在取得这些成果的同时，系统也存在一些不足，如缺少用户注册登录功能、未集成地图直观展示景点位置、缺乏在线预订模块以及数据内容有限等。针对这些问题，后续可考虑增加用户注册与第三方登录、接入高德或百度地图实现定位功能、对接旅游平台提供门票预订服务，并持续丰富旅游信息，以进一步提升系统的实用性与互动性。

​	通过本次毕业设计，我系统学习了Web开发技术，包括HTML5、CSS3、JavaScript、PHP和MySQL，完整经历了从需求分析到功能测试的项目开发流程。本系统虽仍有改进空间，但已能较好地展示宁波旅游资源，为游客提供实用的信息服务，期望能为宁波旅游宣传贡献一份力量。
