# 第一章 绪论

## 1.1 选题背景

在高校的日常教学与管理工作中，毕业设计（论文）及实习相关文档的提交、审核与归档是一项极其重要且繁琐的任务。长期以来，这一过程主要依赖于传统的线下递交或通过电子邮件、即时通讯软件（如微信、QQ）进行文件传输。这种分散的管理模式在实际运行中暴露出诸多痛点：

首先，**文件提交分散且混乱**。学生通过不同渠道提交文件，导致教师需要花费大量时间从海量消息中筛选、下载和整理，极易出现文件遗漏或版本混淆的情况。
其次，**大文件传输受限**。毕业设计往往包含工程图纸、演示视频或大型程序包，普通邮件或即时通讯工具对文件大小有严格限制，且传输过程不稳定，经常出现上传失败或中断的问题。
再次，**审核反馈滞后**。教师对文档的审核意见无法实时反馈给学生，学生也难以即时查询自己的提交状态（如是否通过、是否需修改），导致沟通成本高昂。
最后，**缺乏统一的数据统计**。教务管理人员难以实时掌握全校或全专业的提交进度，无法快速筛选出未交名单，影响了教学管理的效率和质量。

基于上述背景，设计并开发一套专为高校毕业设计场景定制的文件综合管理系统，实现文件的集中存储、规范提交、智能审核与可视化统计，具有重要的现实意义和应用价值。

## 1.2 系统定位

本系统定位为一个**轻量级、高性能的高校毕业设计文件综合管理平台**。它摒弃了传统教务系统臃肿复杂的架构，采用前后端分离的设计思想（逻辑分离，物理同源），专注于解决“文件流转”这一核心问题。

系统的核心设计理念是“**规范流程，高效协作，极致体验**”：

- **规范流程**：通过预设的文档类型（如开题报告、三方协议、毕业论文等）和自动命名规则，强制规范学生的提交行为，确保归档数据整洁有序。
- **高效协作**：为教师提供一站式的审核面板，支持在线预览、快捷打回、批量下载，大幅提升批阅效率。
- **极致体验**：引入现代化的 UI 设计语言（Glassmorphism 毛玻璃风格）和先进的前端技术（分片上传、断点续传），确保在 PC 端和移动端都能提供流畅、美观的使用体验。

## 1.3 设计目标

本系统的设计目标旨在达成以下四个维度的提升：

### 1.3.1 业务流程目标
- 建立从“学生提交”到“教师审核”再到“最终归档”的全链路闭环管理。
- 实现文件版本的自动管理，支持“覆盖更新”，确保服务器端始终保存最新版本。
- 提供精确的权限控制，确保学生只能管理自己的文件，教师只能管理所辖班级的数据。

### 1.3.2 用户体验目标
- **视觉美感**：界面采用流行的“毛玻璃”拟态风格，配合动态背景和细腻的交互动画，消除传统教务系统的沉闷感。
- **操作便捷**：支持文件拖拽上传、多选批量操作、右键菜单等符合直觉的交互方式。
- **响应速度**：页面加载迅速，大文件上传有清晰的进度反馈，拒绝“假死”现象。

### 1.3.3 技术性能目标
- **大文件支持**：通过分片上传技术，支持 GB 级别的大文件稳定传输，并具备断点续传能力。
- **高并发稳定性**：优化数据库连接和文件读写逻辑，确保在毕业提交高峰期系统依然稳定运行。
- **多端适配**：采用响应式布局，完美适配桌面电脑、平板和手机，方便师生随时随地访问。

### 1.3.4 安全性目标
- 实施严格的身份认证（PHP Session），防止未授权访问。
- 对上传文件进行类型校验和安全扫描，防止恶意脚本上传。
- 记录详细的操作审计日志，确保所有关键操作可追溯。
