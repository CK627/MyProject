# 第一章 绪论

## 1.1 选题背景

随着互联网和移动设备的普及，旅游者越来越依赖网络获取旅游信息。宁波市拥有7000年河姆渡文明史，旅游资源丰富，包括天一阁、东钱湖、溪口雪窦山等众多知名景点，以及汤圆、海鲜等特色美食。设计一个专业的旅游宣传网页，能够有效展示宁波旅游资源，为游客提供便捷的信息服务。

## 1.2 选题目的与意义

本课题主要是为了设计并实现一个宁波旅游宣传网页。它的核心目的，是希望用数字化的方式，把宁波丰富的旅游资源和文化历史更直观地展现出来，让大家不用到处找攻略，就能在一个地方看全。

对游客来说，这个网站想做成一个好用的工具：大家可以在这里看景点、找美食、查住宿和交通，还能互相留言分享真实的游玩心得。对开发者而言，这也是一次把平时学到的 HTML、CSS、JavaScript 前端页面技术，以及 PHP、MySQL 后端数据库技术结合起来，做成一个完整项目的实践机会。

## 1.3 研究内容

本系统在设计上主要考虑两类人的使用：一类是来找旅游信息的游客，另一类是负责维护网站内容的管理员。

在游客这边，网站重点解决“去哪玩、怎么去”的问题。游客打开首页就能大致了解宁波的特色，接着可以根据自己的兴趣去查具体的景点和地道美食；定好行程后，还能接着看住宿推荐和交通路线，参考别人的游玩攻略。一趟玩下来，也可以在留言板里写下自己的感受。整个过程就是顺着“随便看看——按需查询——参考决策——留言反馈”的思路来的。

在管理员这边，主要工作就是保证网站上的信息是最新、最准的。比如有新的景点开放或者门票价格变了，管理员就要在后台及时更新这些基础数据；同时，为了保证大家看到的内容都是健康有用的，管理员还得负责审核游客发上来的留言和评论。也就是通过这样日常的“维护、更新、审核”，让网站能一直好好地运转下去。
