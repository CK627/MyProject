# 第一章 绪论

## 1.1 选题背景

随着互联网和移动设备的普及，旅游者越来越依赖网络获取旅游信息。宁波市拥有7000年河姆渡文明史，旅游资源丰富，包括天一阁、东钱湖、溪口雪窦山等众多知名景点，以及汤圆、海鲜等特色美食。设计一个专业的旅游宣传网页，能够有效展示宁波旅游资源，为游客提供便捷的信息服务。

## 1.2 选题目的与意义

本课题旨在设计并实现一个宁波旅游宣传网页，主要目的：

1. **全面展示宁波旅游资源**：通过图文并茂的方式展示景点、美食、住宿、交通等信息
2. **提供实用旅游服务**：为游客提供攻略指南、交通查询等实用功能
3. **搭建互动平台**：通过留言和评论功能，让游客分享旅行体验
4. **实践Web开发技术**：将所学HTML、CSS、JavaScript、PHP、MySQL等技术综合应用

## 1.3 研究内容

本系统分为**前台展示**和**后台管理**两大部分：

**前台展示系统（面向游客）：**
- 首页展示
- 景点浏览
- 美食推荐
- 住宿查询
- 交通指南
- 旅游攻略
- 游客留言

**后台管理系统（面向管理员）：**
- 管理员登录
- 内容管理（景点/美食/住宿/交通/攻略）
- 留言管理
- 评论审核
