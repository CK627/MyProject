# 区块链式随机数生成器 (Blockchain Random Number Generator)

> 这是一个基于简化版区块链技术思想的随机数生成器项目，使用 Python Flask 框架构建 Web 应用。项目通过模拟区块链的工作原理，利用工作量证明（Proof of Work）机制生成具备不可预测性的随机数。

## 📖 项目简介

**BlockchainRandomNumberGenerator** 是一个极简的区块链概念演示项目。它在后端维护了一条简单的区块链结构，当用户每次访问网页时，系统会尝试“挖矿”（计算满足特定数学条件的工作量证明 Proof of Work），一旦计算成功，便会生成一个新区块追加到链上。最后，系统利用新区块的哈希特征，通过取模运算生成一个范围内的随机数返回给前端展示。

本项目非常适合用来学习理解**区块链的基础结构**、**哈希运算**以及**工作量证明（PoW）**的原理。

## 🌟 主要功能与特性

- 🔗 **区块链核心机制**：实现了一个单节点的内存区块链结构，包含区块索引、时间戳、前置哈希和工作量证明（Proof）。
- ⚡ **工作量证明 (PoW)**：设计了简化的挖矿算法 `(previous_proof * proof) % 23 == 0`，只有通过大量随机尝试找到合法的 `proof` 才能生成新区块。
- 🎲 **伪随机数生成**：基于新生成的区块数据的整体哈希值，通过取模运算（`hash(str(block)) % 53`）生成结果。
- 🌐 **Web 界面交互**：提供简洁的 Flask Web 界面，每次刷新页面即触发一次“挖矿”并展示最新的随机数。

## 🛠 技术架构

- **核心语言**: Python 3.6+
- **Web 框架**: Flask
- **核心依赖**: Python 标准库（`random`, `time`,内置的 `hash` 函数）

### 算法原理解析

当用户请求随机数时，系统执行以下步骤：
1. **获取最新区块**：读取链上最后一个区块，获取它的 `proof` 值作为 `previous_proof`。
2. **工作量证明 (挖矿)**：在 `1` 到 `1000000` 之间不断随机生成 `proof` 测试值，直到满足条件 `(previous_proof * proof) % 23 == 0`。
3. **创建新区块**：将计算出的合法 `proof` 和前一个区块的哈希打包，生成新的区块并上链。
4. **计算随机数**：将整个新区块字典转换为字符串，计算其内存哈希值，然后对 53 取模，得到最终的随机数 `(0~52)`。

## ⚙️ 环境配置与安装

```bash
git clone https://github.com/CK627/BlockchainRandomNumberGenerator.git

pip install flask
```

## 🚀 启动与使用步骤

1. **运行项目**
   在项目根目录下执行：
   ```bash
   python BlockchainRandomNumberGenerator.py
   ```
   *(默认会在本地启动调试服务器)*

2. **访问应用**
   打开浏览器访问：`http://127.0.0.1:5000`。
   每次刷新页面，后端都会计算新的工作量证明，创建新区块并返回一个新的随机数。

## ⚠️ 注意事项与局限性

- **安全性声明**：本项目使用的 Python 内置 `hash()` 函数在每次 Python 进程重启时都会加盐（随机化），且挖矿算法高度简化。此随机数**绝对不能**用于密码学或涉及资金安全的真实区块链应用中，仅作为原理演示。
- **持久化**：当前的区块链数据完全存储在内存的列表中，重启 Flask 服务后区块链将重置为只有创世区块的状态。

- [ ] **区块链浏览器**：增加一个页面路由（如 `/chain`），以 JSON 格式完整展示当前链上的所有区块数据。
