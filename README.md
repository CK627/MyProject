# BitTally（浏览器端二进制定位小工具）

BitTally 是一个**纯前端、单 HTML 文件**的小工具：在浏览器中选择一个本地二进制文件（如镜像、转储、固件等），程序会**从文件开头开始扫描**，找到**第一个非 0 字节**的位置，并输出：

- **扇区（Sector）**：以 **512 字节**为单位的扇区号（十六进制）
- **偏移（Offset）**：该非 0 字节在文件中的**绝对偏移**（十六进制，默认补齐到 9 位）

该项目提供了多个版本（可读性版、极简版、IE 兼容版、注释版等），便于在不同场景使用或学习代码压缩（Code Golf）过程。

---

## 适用场景

- 快速判断一个大文件/镜像从哪里开始出现非零数据
- 定位“前导全 0”区域结束位置（如某些导出镜像、分区镜像、固件文件）
- 作为学习材料：FileReader 分片读取、TypedArray 处理、以及从可读代码到极简代码的演进

> 说明：本工具默认只定位“**第一个**非零字节”，不是全文统计/搜索器。

---

## 技术栈与关键 API

- **HTML5**
- **JavaScript（ES5/ES6，视版本而定）**
- 浏览器文件读取：
  - `FileReader.readAsArrayBuffer(...)`
  - `Blob/File.slice(start, end)`（分片读取）
- 二进制处理：
  - `Uint8Array`（TypedArray）
- 输出展示：
  - `innerText` 或 `document.body.innerText`
- 兼容性处理（IE 版）：
  - `event.srcElement`
  - 不使用箭头函数 `=>`
  - 不使用 `String.prototype.padStart`

## 如何使用（无需安装）

1. 在本仓库/目录中，双击打开任意一个 HTML 文件（推荐先用可读性版本）。
2. 页面上会出现“选择文件”的按钮。
3. 选择要分析的文件后，页面会显示结果：
   - `扇区: <HEX>`
   - `偏移: <HEX>`
4. 如果扫描到文件末尾仍未发现非 0 字节，会显示：`未发现`

提示：
- 全程在本地浏览器内运行，**不会上传文件内容**。
- 文件越大，扫描时间越长（线性扫描）。

## 实现原理（核心流程）

1. 用户在 `<input type="file">` 选择文件
2. 以固定大小分片读取（常见为 `1e6` ≈ 1MB，或 `1024*1024`）
3. `FileReader` 读取分片为 `ArrayBuffer`
4. 将 `ArrayBuffer` 转为 `Uint8Array`，逐字节扫描
5. 一旦发现某字节 `!== 0`：
   - 计算全局偏移：`p = offset + i`
   - 计算扇区号：`sector = Math.floor(p / 512)`（极简版常用 `p >> 9`）
   - 输出十六进制结果并结束
6. 若本片段全为 0，则将 `offset += bytes.length`，继续读取下一片段，直到读完文件

## 可配置项（按需修改源码）

不同版本写法不同，但关键参数一致：

- **分片大小（chunk size）**：
  - 常见：`1e6`（1,000,000 字节，约 1MB）
  - 或：`1024 * 1024`（1,048,576 字节）
  - 调大：读片次数更少，但单次内存/卡顿更明显
  - 调小：更平滑，但读片次数更多

- **扇区大小（sector size）**：
  - 默认：`512` 字节
  - 如需改为 4096（高级格式硬盘/某些场景），可将：
    - `p >> 9` 改为 `Math.floor(p / 4096)` 或使用位移 `p >> 12`（4096 = 2¹²）

- **偏移十六进制补齐位数**：
  - 现代版：`padStart(9, '0')`
  - IE 版：`while(h.length<9) h='0'+h;`

## 常见问题（FAQ）

### 1) 打开 HTML 后没有反应？

请确认你是在支持 File API 的浏览器中打开（现代浏览器基本都支持；IE 请用 `BitTally_IE.html`）。

### 2) 大文件会不会卡？

会。该工具本质是线性扫描，最坏情况需要读完整个文件。分片读取能降低峰值内存，但仍可能因为读取与循环扫描而卡顿。可尝试减小分片大小。

### 3) 工具会上传我的文件吗？

不会。工具逻辑全部在本地浏览器内执行，代码也不包含网络请求逻辑。

### 4) 为什么只输出第一个非 0 的位置？

这是当前设计目标（快速定位“首次出现非零数据”）。如需找全部位置/统计，可在找到后不 `return`，改为继续扫描并累积结果（注意性能与输出方式）。
